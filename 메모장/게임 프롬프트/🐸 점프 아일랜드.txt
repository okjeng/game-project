# 🐸 점프 아일랜드 — 가족용 무한 상승 아케이드 게임

새로운 웹 게임을 만들어줘.

게임 이름은 임시로 **"점프 아일랜드(Jump Island)"**로 한다.

기존의 "무한의 계단"류 게임에서 재미있는 핵심 요소인

* 자동으로 계속 올라가는 진행 방식
* 좌우 방향을 순간적으로 선택하는 조작
* 빠른 판단
* 높은 점수에 도전하는 구조

만 참고한다.

**중요: 기존 게임의 화면, 캐릭터, 계단 디자인, 애니메이션, UI, 게임 규칙을 그대로 복제하지 않는다.**

이번 게임은 완전히 다른 세계관과 플레이 구조를 가진 독창적인 가족용 아케이드 게임으로 제작한다.

━━━━━━━━━━━━━━━━━━━━━━

1. 핵심 콘셉트
   ━━━━━━━━━━━━━━━━━━━━━━

플레이어 캐릭터가 작은 섬과 발판을 하나씩 밟으면서 위쪽으로 이동한다.

캐릭터는 자동으로 점프한다.

플레이어는 캐릭터가 다음 발판으로 이동하기 전에 방향을 선택해야 한다.

하지만 일반적인 계단을 오르는 방식이 아니다.

게임 공간은 다음과 같은 **떠다니는 섬들**로 구성한다.

🌴 작은 섬
☁️ 구름 발판
🍄 버섯 발판
🪨 바위 발판
🌈 무지개 발판
⭐ 보너스 발판

캐릭터가 발판에 착지하면 다시 자동으로 점프한다.

플레이어는 순간적으로 다음 발판의 위치를 보고 이동 방향을 선택한다.

목표:

**최대한 오래 살아남으며 가장 높은 곳까지 올라가기.**

━━━━━━━━━━━━━━━━━━━━━━
2. 기존 무한의 계단과 확실히 다르게 만들 것
━━━━━━━━━━━━━━━━━━━━━━

다음 요소는 사용하지 않는다.

* 계단이 일렬로 반복되는 구조
* 계단을 단순히 왼쪽/오른쪽으로 반복하는 디자인
* 기존 무한의 계단 캐릭터와 유사한 캐릭터
* 기존 게임과 유사한 색상이나 UI
* 기존 게임의 애니메이션 복제
* 기존 게임의 사운드 복제
* 기존 게임의 그래픽을 그대로 재현

대신 다음을 사용한다.

**"하늘 위에 떠 있는 작은 섬을 점프하며 올라가는 게임"**

으로 완전히 차별화한다.

━━━━━━━━━━━━━━━━━━━━━━
3. 캐릭터
━━━━━━━━━━━━━━━━━━━━━━

캐릭터는 가족들이 좋아할 만한 귀여운 오리지널 캐릭터로 만든다.

예:

🐰 토끼
🐱 고양이
🐸 개구리
🐼 판다
🐧 펭귄

초기 기본 캐릭터는 귀여운 **개구리 캐릭터**로 한다.

디자인:

* 둥근 머리
* 큰 눈
* 작은 몸
* 짧은 팔다리
* 밝고 친근한 표정
* 작은 배낭
* 여행자 느낌

캐릭터가 점프할 때:

살짝 몸이 눌렸다가
↓
위로 점프
↓
공중에서 살짝 회전
↓
발판에 착지

하는 부드러운 애니메이션을 사용한다.

캐릭터 디자인은 기존 유명 게임 캐릭터를 연상시키지 않도록 독창적으로 만든다.

━━━━━━━━━━━━━━━━━━━━━━
4. 게임 세계
━━━━━━━━━━━━━━━━━━━━━━

배경은 하늘이다.

게임이 진행될수록 배경도 변화한다.

초반:

☀️ 맑은 하늘

중반:

🌅 노을

고득점:

🌌 밤하늘

고득점 이후:

🌠 별이 흐르는 우주

이렇게 자연스럽게 분위기가 변하도록 한다.

배경은 단순한 이미지 한 장이 아니라 패럴랙스 효과를 사용해 움직이는 것처럼 보이게 한다.

━━━━━━━━━━━━━━━━━━━━━━
5. 발판 시스템
━━━━━━━━━━━━━━━━━━━━━━

게임의 핵심이다.

일반적인 계단 대신 다양한 형태의 발판을 사용한다.

기본:

🟢 일반 섬

특수 발판:

⭐ 보너스 섬
💨 이동 섬
🌀 순간이동 섬
🌈 점프 강화 섬
🧊 미끄러운 섬
🔥 위험 섬

초기 MVP에서는 다음 3개만 구현한다.

1. 일반 섬
2. 이동 섬
3. 보너스 섬

나머지는 이후 확장한다.

━━━━━━━━━━━━━━━━━━━━━━
6. 기본 조작
━━━━━━━━━━━━━━━━━━━━━━

PC:

* ← 방향키
* → 방향키
* A
* D

모바일:

* 화면 왼쪽 터치
* 화면 오른쪽 터치

또는

화면 좌우 스와이프

한 번의 입력으로 다음 이동 방향을 결정한다.

캐릭터는 자동으로 점프한다.

즉 플레이어는 계속 버튼을 누르는 것이 아니라,

**"다음 발판은 어디에 있는가?"**

를 보고 순간적으로 판단한다.

━━━━━━━━━━━━━━━━━━━━━━
7. 방향 시스템
━━━━━━━━━━━━━━━━━━━━━━

게임이 시작되면 캐릭터가 첫 번째 섬에 있다.

다음 섬이 왼쪽에 있으면:

←

다음 섬이 오른쪽에 있으면:

→

플레이어가 올바른 방향을 선택하면 다음 섬으로 점프한다.

잘못된 방향을 선택하면:

* 섬을 놓침
* 아래로 떨어짐
* GAME OVER

단, 초반에는 너무 어렵게 만들지 않는다.

발판 사이의 거리를 충분히 확보한다.

━━━━━━━━━━━━━━━━━━━━━━
8. 랜덤 맵
━━━━━━━━━━━━━━━━━━━━━━

매 게임마다 발판의 위치가 조금씩 달라져야 한다.

단순한 완전 랜덤은 사용하지 않는다.

플레이어가 항상 도달할 수 있도록 생성 규칙을 만든다.

예:

현재 섬

```
    🟢
   /   \
 🟢     🟢
```

다음 섬

```
    🟢
      \
       🟢
```

다음

```
  🟢
 /
```

🟢

이런 식으로 매번 새로운 경로가 만들어진다.

중요:

**절대로 도달할 수 없는 발판을 생성하지 않는다.**

━━━━━━━━━━━━━━━━━━━━━━
9. 움직이는 섬
━━━━━━━━━━━━━━━━━━━━━━

일정 거리 이상 진행하면 움직이는 발판이 등장한다.

예:

🟢 ─────────→ 🟢

섬이 좌우로 이동한다.

플레이어는 움직이는 섬의 타이밍을 보고 점프해야 한다.

난이도가 점진적으로 올라간다.

━━━━━━━━━━━━━━━━━━━━━━
10. 보너스 섬
━━━━━━━━━━━━━━━━━━━━━━

⭐ 보너스 섬에 착지하면 특별한 보너스를 준다.

예:

+100점

또는

+3 COMBO

또는

🪙 코인 +1

보너스 섬은 일반 발판보다 눈에 띄게 디자인한다.

하지만 플레이어가 반드시 먹어야 하는 구조는 아니다.

━━━━━━━━━━━━━━━━━━━━━━
11. 콤보 시스템
━━━━━━━━━━━━━━━━━━━━━━

연속으로 안전하게 착지하면 콤보가 올라간다.

예:

COMBO x2
COMBO x3
COMBO x5
COMBO x10

콤보가 높아질수록 점수 보너스를 준다.

잘못된 이동으로 실패하면 콤보가 초기화된다.

━━━━━━━━━━━━━━━━━━━━━━
12. 점수 시스템
━━━━━━━━━━━━━━━━━━━━━━

기본 점수:

발판 1개 착지
= +10

보너스 섬
= +100

연속 착지
= 콤보 보너스

특별한 구간 통과
= 추가 점수

게임 종료 후:

최종 점수
최고 높이
최고 콤보
획득 코인

을 표시한다.

━━━━━━━━━━━━━━━━━━━━━━
13. 높이 시스템
━━━━━━━━━━━━━━━━━━━━━━

단순한 "점수"만 보여주지 않는다.

현재 얼마나 높이 올라왔는지도 표시한다.

예:

HEIGHT

128m

또는

🌤️ 128m

진행할수록 높이가 증가한다.

특정 구간:

100m
500m
1,000m
5,000m

등에 도달하면 새로운 배경을 보여준다.

━━━━━━━━━━━━━━━━━━━━━━
14. 이벤트 구간
━━━━━━━━━━━━━━━━━━━━━━

게임이 계속 반복되면 지루해지기 때문에 일정 높이마다 특별한 구간을 넣는다.

예:

100m
☁️ 구름 구간

300m
🌈 무지개 구간

500m
🌌 밤하늘 구간

1,000m
🌠 별똥별 구간

이런 식으로 플레이하면서 새로운 배경이 등장하게 한다.

━━━━━━━━━━━━━━━━━━━━━━
15. 특별 이벤트
━━━━━━━━━━━━━━━━━━━━━━

가끔 랜덤 이벤트가 발생한다.

예:

🌪️ 강한 바람

화면이 살짝 흔들리고 발판 움직임이 빨라진다.

또는

🌈 무지개 길

잠시 동안 보너스 발판이 연속으로 등장한다.

또는

⭐ 별비

짧은 시간 동안 코인이 많이 등장한다.

이벤트는 너무 복잡하게 만들지 않는다.

━━━━━━━━━━━━━━━━━━━━━━
16. 게임 속도
━━━━━━━━━━━━━━━━━━━━━━

처음에는 매우 느리고 쉽게 시작한다.

예:

초반
→ 점프 간격 넓음
→ 발판 크기 큼
→ 이동 속도 느림

중반
→ 발판 간격 증가
→ 이동 섬 등장
→ 점프 타이밍 어려워짐

후반
→ 발판 크기 감소
→ 이동 섬 증가
→ 이벤트 증가
→ 속도 증가

단계적으로 난이도를 높인다.

━━━━━━━━━━━━━━━━━━━━━━
17. 카메라
━━━━━━━━━━━━━━━━━━━━━━

카메라는 캐릭터를 따라 위로 이동한다.

하지만 화면이 단순히 위로 밀리는 느낌이 아니라,

캐릭터가 화면의 중앙 부근에 유지되고
배경과 발판이 아래쪽으로 자연스럽게 이동하는 방식으로 만든다.

카메라 이동은 부드럽게 보간한다.

갑자기 화면이 튀지 않도록 한다.

━━━━━━━━━━━━━━━━━━━━━━
18. 시작 화면
━━━━━━━━━━━━━━━━━━━━━━

게임 시작 화면:

🐸 JUMP ISLAND

"끝없이 펼쳐진 하늘섬을 올라가세요!"

[ ▶ 게임 시작 ]

🏆 최고 기록
HEIGHT 1,280m

처음 시작하는 사람을 위해 아주 짧은 안내:

← 왼쪽으로 이동

→ 오른쪽으로 이동

"다음 섬에 착지하세요!"

게임 화면을 UI가 가리지 않도록 한다.

━━━━━━━━━━━━━━━━━━━━━━
20. 캐릭터 선택
━━━━━━━━━━━━━━━━━━━━━━

초기 버전에서는 개구리 하나만 사용한다.

하지만 이후 확장할 수 있도록 구조를 만든다.

추후:

🐸 개구리
🐰 토끼
🐱 고양이
🐼 판다
🐧 펭귄

등을 추가할 수 있도록 한다.

캐릭터마다 능력치 차이를 크게 주지 않는다.

가족용 게임이므로 과도한 과금형 능력 차이는 만들지 않는다.

━━━━━━━━━━━━━━━━━━━━━━
21. 코인 시스템
━━━━━━━━━━━━━━━━━━━━━━

게임 중 코인을 획득할 수 있다.

🪙

코인은 나중에 캐릭터나 꾸미기 요소를 해금하는 데 사용할 수 있도록 구조만 준비한다.

MVP에서는:

코인 획득
코인 표시
localStorage 저장

까지만 구현한다.

━━━━━━━━━━━━━━━━━━━━━━
22. 게임 오버
━━━━━━━━━━━━━━━━━━━━━━

캐릭터가 발판을 놓치면 떨어진다.

단순히 바로 검은 화면으로 전환하지 않는다.

24. 가족용 디자인
━━━━━━━━━━━━━━━━━━━━━━

이 게임은 가족들이 함께 사용하는 사이트에 들어갈 게임이다.

따라서:

* 귀여운 분위기
* 폭력성 없음
* 공포 요소 없음
* 과도한 번쩍임 없음
* 너무 어려운 조작 없음
* 짧은 플레이 시간
* 즉시 재시작 가능

을 기본 원칙으로 한다.

사운드는 귀엽고 가벼운 효과음으로 구성한다.

브라우저 자동재생 정책을 고려한다.

27. 애니메이션
━━━━━━━━━━━━━━━━━━━━━━

* 캐릭터 점프
* 캐릭터 착지
* 발판 이동
* 카메라 이동
* 코인 회전
* 보너스 효과
* 콤보 표시
* 배경 패럴랙스
* 게임 오버 낙하

모든 애니메이션은 부드럽게 만든다.

특히 캐릭터 점프가 게임의 핵심이므로
점프 → 공중 → 착지의 움직임이 자연스러워야 한다.

28. 성능
━━━━━━━━━━━━━━━━━━━━━━

웹 브라우저에서 부드럽게 작동해야 한다.

게임 루프는 requestAnimationFrame을 사용한다.

발판을 무한히 DOM에 생성하지 않는다.

화면 밖으로 사라진 발판은 제거하거나 재사용한다.

필요하면 object pooling 구조를 사용한다.

게임 종료 시:

* animation frame 정리
* event listener 정리
* timer 정리

를 반드시 수행한다.

게임은 독립적인 컴포넌트 또는 모듈로 구성한다.

33. 게임 생성 알고리즘
━━━━━━━━━━━━━━━━━━━━━━

발판을 완전 랜덤으로 생성하지 않는다.

현재 발판에서 플레이어가 실제로 도달할 수 있는 범위 내에서 다음 발판을 생성한다.

* y 위치

* type
* movementSpeed
* direction

* 발판 간격 증가
* 발판 크기 감소
* 이동 발판 증가
* 이벤트 증가

등으로 난이도를 조절한다.

10. 높이

이다.

그 이후:

3. 코인
4. 콤보

35. 가장 중요한 요구사항
━━━━━━━━━━━━━━━━━━━━━━

이 게임은 "무한의 계단 복제품"이 되어서는 안 된다.

핵심 재미만 참고하고,
게임의 시각적 표현과 세계관과 플레이 공간은 완전히 다르게 만든다.

최종적으로 사용자가 게임을 보면:

"무한의 계단 같은 게임"

이라고 느끼는 것이 아니라

"하늘섬을 점프하면서 계속 올라가는 새로운 게임"

이라고 느껴야 한다.

**게임의 재미는 단순한 조작에서 나오되,
게임의 개성은 떠다니는 섬, 귀여운 캐릭터, 변화하는 하늘, 이동 발판, 보너스 이벤트에서 나오도록 한다.**

먼저 현재 프로젝트 구조를 분석한 뒤,
구현 계획을 간단히 정리하고,
MVP부터 실제 코드로 구현한다.

각 단계가 완료될 때마다 실제 브라우저에서 실행하여
조작, 충돌, 발판 생성, 카메라 이동, 게임 오버가 정상적으로 작동하는지 확인한다.
